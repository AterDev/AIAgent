USAGE EXAMPLES

### Get Execution Progress
curl GET /api/workflow-execution/{id}/progress

Response:
{
  "executionId": "...",
  "status": "Running",
  "totalSteps": 5,
  "completedSteps": 3,
  "progressPercentage": 60.0,
  "steps": [...],
  "currentStepName": "Step 4"
}

### Resume from Checkpoint
curl POST /api/workflow-execution/{id}/resume?fromStep=3

### Retry Failed Execution  
curl POST /api/workflow-execution/{id}/retry

### Cancel Execution
curl POST /api/workflow-execution/{id}/cancel
