# 总体功能说明

该项目目的是提供一个开箱即用的，使用方便的模型管理和Agent管理平台，方便团队能够快速获取相关能力。

## 核心功能

- 模型管理与监控
- RAG
- Agent
- 工作流
- MCP工具
- 开放平台


## 技术选型

### 语言模型

根据不同的场景选择合适的语言模型，遵循OpenAI最新标准（GPT-4.1/GPT-5及更高版本）：

#### 模型选择策略

| 场景 | 推荐模型(OpenAI) | 国产替代方案 | 支持 Responses API | 说明 |
|-----|---------|---------|--------|------|
| 向量化/嵌入 | text-embedding-3-small/large | 通义千问-Text-Embedding-3 / 智谱-Embedding-3 | ✗ | 用于RAG中的文档向量化 |
| 意图识别 | GPT-4.1-mini | 通义千问-Plus / 智谱-GLM-4-Flash | ✓ | 快速分类和意图识别 |
| 知识图谱构建 | GPT-4.1 | 通义千问-Max / 智谱-GLM-4-Plus | ✓ | 结构化输出和关系抽取 |
| 内容总结/提取 | GPT-4.1 | 通义千问-Max / 文心4.0 | ✓ | 文档摘要和关键信息抽取 |
| 文档解析 | GPT-4 Vision | 通义千问-Vision / 文心4.0-Vision | ✗ | 多模态文档解析和OCR |
| Agent推理/工作流 | GPT-5/o1 | 通义千问-Latest / 文心4.0-Long-Context | ✓ | 复杂任务和多步推理 |

#### 模型选择要点

根据场景选择合适的模型版本，优先选择OpenAI官方最新版本，不支持时选择对应的国产替代方案。

## RAG (Retrieval-Augmented Generation)

提供文档管理、解析和知识库检索能力。

### 主要功能

- **文档管理**：支持多种格式（PDF、Word、Excel、Markdown、文本等）的上传、导入、分类和访问控制
- **文档解析**：自动提取内容、识别结构、生成摘要和关键词
- **向量存储**：将文档转换为向量表示，支持向量数据库存储
- **知识库检索**：支持语义检索和关键词检索的混合查询

### 支持的文档格式

- 文本类：TXT、Markdown、JSON、XML
- Office：PDF、DOCX、PPTX、Excel
- 媒体：图片（JPG、PNG）、扫描件（OCR识别）

## Agent

配置和管理 AI Agent，支持多标签分类管理。

### 主要功能

- **Agent 配置**：定义 Agent 的角色、能力和系统提示词
- **工具集成**：支持 OpenAI Function Calling 和 MCP 工具调用
- **状态管理**：会话状态、上下文管理
- **执行监控**：执行轨迹、工具调用日志、性能指标

## MCP 工具

Model Context Protocol（MCP）是用于标准化 AI 应用与外部工具和数据源集成的开源标准。

### 主要特性

- **工具类型**：支持文件系统工具、数据库工具、API 集成工具
- **资源管理**：工具、资源、提示词三种资源类型
- **权限控制**：基于用户角色的访问控制和权限隔离
- **传输方式**：支持 stdio、HTTP、WebSocket 等多种传输方式

## 工作流

定义和执行自动化工作流，支持多标签分类管理。

### 主要功能

- **工作流定义**：支持 Agent 调用、工具调用、条件分支、数据转换等步骤
- **执行模式**：支持顺序执行、并行执行、条件分支
- **状态管理**：工作流执行状态跟踪和进度监控
- **错误处理**：支持重试、降级、中止等错误处理策略

## 开放平台

提供开放的 API 接口，方便二次开发和集成。

### API 能力

- **模型管理**：获取可用模型列表、查询模型能力
- **Agent 管理和调用**：创建、查询、更新、删除、调用 Agent
- **文档处理和 RAG**：文档上传、查询、知识库检索
- **工作流管理**：创建、查询、更新、删除、执行工作流
- **MCP 工具注册**：注册 MCP 服务器、查询工具、调用工具

### 认证和安全

- **认证方式**：OAuth 2.0、API Key、JWT Token
- **速率限制**：基于用户和 IP 的调用限制
- **数据加密**：传输层和存储层加密
