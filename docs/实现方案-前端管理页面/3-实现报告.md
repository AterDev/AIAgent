## 功能特性

### 模型在线调试页面

**核心功能**:
- 🎯 选择不同 AI 模型进行测试
- ⚙️ 配置模型参数（温度、最大 token、系统提示词）
- 📊 实时查看响应和 Token 统计
- 📜 测试历史记录（保留最近 10 次）
- 💾 导出测试结果

**技术亮点**:
- 使用 Signals 实现响应式状态管理
- 表单验证确保数据有效性
- 清晰的卡片布局和分栏设计

### AI Agent 配置与调试页面

**核心功能**:
- 🤖 Agent 选择和配置管理
- 🔧 高级参数配置（温度、流式输出等）
- 💬 实时测试对话交互
- 🛠️ 工具调用详情展示
- 📋 执行历史和重运行

**技术亮点**:
- 使用 computed 实现派生状态
- MatExpansionPanel 优化长内容展示
- 详细的工具调用输入/输出追踪

### 工作流编排监控页面

**核心功能**:
- 📈 实时统计面板（运行数、成功率等）
- ⏱️ 运行中工作流实时监控
- 📋 历史执行记录查看
- 🔄 工作流步骤时间线
- ❌ 取消和重试功能

**技术亮点**:
- RxJS interval 实现自动刷新（每 5 秒）
- 进度条实时显示执行进度
- 时间线视图展示步骤流程
- 脉冲动画标记运行中步骤

## 技术架构

### 前端技术栈
- **框架**: Angular 21+ (Standalone Components)
- **状态管理**: Signals
- **UI 组件**: Angular Material 21
- **响应式编程**: RxJS 7.8
- **样式**: SCSS
- **类型检查**: TypeScript 5.9

### 设计模式
- Standalone Components (减少模块依赖)

- Reactive Forms (表单管理)
- Lazy Loading Routes (按需加载)

- 使用 Material Design 规范
