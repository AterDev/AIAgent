## 🎯 功能特性

### 1. 模型在线调试 (`/model-debug`)
**核心价值**: 快速验证模型性能和行为

**主要功能**:
- ✅ 模型选择（从可用模型列表）
- ✅ 参数配置（温度、最大 token、系统提示词）
- ✅ 实时测试和响应展示
- ✅ Token 使用统计（Prompt/Completion/Total）
- ✅ 响应时间追踪
- ✅ 测试历史记录（最近 10 次）
- ✅ 快速加载历史配置
- ✅ 导出测试结果

**使用场景**:
- 评估不同模型的响应质量
- 调试提示词效果
- 测试参数对输出的影响
- Token 使用优化

### 2. AI Agent 配置与调试 (`/agent-debug`)
**核心价值**: 全面的 Agent 开发和调试工具

**主要功能**:
- ✅ Agent 选择和基本信息展示
- ✅ 系统提示词覆盖
- ✅ 高级参数配置
  - 温度
  - 最大 Token
  - 流式输出开关
  - 工具调用日志开关
- ✅ 实时对话测试
- ✅ 完整消息历史展示
- ✅ 工具调用详情
  - 工具名称
  - 输入参数
  - 输出结果
  - 执行时间
- ✅ 执行统计
  - 状态（completed/error/running）
  - 耗时
  - Token 使用
  - 工具调用次数
- ✅ 执行历史和重运行
- ✅ 导出调试会话

**使用场景**:
- Agent 开发和调试
- 工具调用验证
- 对话流程测试
- 性能优化分析

### 3. 工作流编排监控 (`/workflow-monitor`)
**核心价值**: 实时洞察工作流执行状态

**主要功能**:
- ✅ 实时统计面板
  - 运行中数量
  - 已完成数量
  - 成功率
  - 平均执行时间
- ✅ 运行中工作流
  - 实时进度条
  - 自动刷新（5秒间隔）
  - 手动刷新
  - 取消执行
- ✅ 历史执行记录
  - 状态展示
  - 执行时间
  - 重试功能（失败的工作流）
- ✅ 执行详情
  - 步骤时间线
  - 每步状态（pending/running/completed/failed）
  - 步骤输入输出
  - 错误信息
  - 整体输入输出
- ✅ 可视化
  - 脉冲动画标记运行中步骤
  - 颜色编码状态
  - 时间线视图
- ✅ 导出执行详情

**使用场景**:
- 监控工作流执行状态
- 调试工作流失败原因
- 分析执行性能
- 验证业务流程

## 🛠️ 技术实现

### 技术栈
- **框架**: Angular 21.1.0 (Standalone Components)
- **状态管理**: Angular Signals
- **UI 组件**: Angular Material 21.0.1
- **响应式**: RxJS 7.8.2
- **样式**: SCSS
- **类型**: TypeScript 5.9.3

### 关键技术点

1. **Signals 响应式状态**
   ```typescript
   isLoading = signal(false);
   response = signal<Response | null>(null);
   computed(() => this.data().totalCount);
   ```

2. **RxJS 异步流**
   ```typescript
   interval(5000).subscribe(() => {
     if (this.autoRefresh()) {
       this.refreshData();
     }
   });
   ```

3. **Lazy Loading 路由**
   ```typescript
   loadComponent: () => import('./pages/model-debug/index/index')
     .then(m => m.ModelDebugIndex)
   ```

4. **Material Design 组件**
   - MatCard
   - MatTable
   - MatExpansionPanel
   - MatProgressBar
   - MatChipSet

## ⚠️ 注意事项

### 当前限制

1. **使用模拟数据**: 
   - 所有页面当前使用模拟数据
   - 需要后端实现对应的 API 接口

2. **轮询而非实时推送**:
   - 工作流监控使用 5 秒轮询
   - 建议后续集成 SignalR 实现真正的实时推送

3. **缺少单元测试**:
   - 代码通过编译但缺少测试
   - 建议补充单元测试和 E2E 测试

### 依赖的后端 API

需要实现以下 API 才能完整工作：

```typescript
// 模型调试
POST /api/debug/model-test
{
  modelId: string;
  systemPrompt: string;
  prompt: string;
  temperature: number;
  maxTokens: number;
}

// Agent 调试
POST /api/debug/agent-test
{
  agentId: string;
  userMessage: string;
  config: {...};
}

// 工作流控制
POST /api/workflow-execution/{id}/cancel
POST /api/workflow-execution/{id}/retry
```
