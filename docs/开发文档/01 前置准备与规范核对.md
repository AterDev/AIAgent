# 01 前置准备与规范核对

## 目标

在开始编码前统一项目结构认知、技术约束与开发规范，避免后续返工。

## 步骤

1. **阅读核心需求**
   - 研读 docs 目录中《总体功能说明》《技术详细设计文档》。
   - 明确核心模块：模型管理、RAG、Agent、MCP、工作流、开放平台。

2. **核对 Perigon 模板规范**
   - 阅读 .github/copilot-instructions.md。
   - 阅读 .github/skills/backend/SKILL.md 与 .github/skills/perigon/SKILL.md。
   - 明确分层：Definition -> Modules -> Services；ManagerBase 模式、DTO 结构、Controller 约定。

3. **检查项目结构与模块**
   - 重点确认目录：
     - src/Definition/Entity
     - src/Definition/EntityFramework
   - src/Modules/{CoreMod,AIAgentMod,SystemMod}
     - src/Services/{ApiService,AdminService}
     - src/AppHost

4. **Aspire + 依赖服务准备**
   - AppHost 中检查 Aspire 服务编排（PostgreSQL、Qdrant、NATS、Redis）。
   - 确认本地 DevUI/管理工具配置路径。

5. **AI 能力与 MAF（Microsoft Agent Framework）准备**
   - 核对 MAF 相关依赖与使用策略（仅作为 Agent 引擎基础）。
   - 统一模型调用接口后再对接 MAF 扩展。

6. **环境与安全**
   - 统一配置密钥与连接串的环境变量/配置键。
   - 约定多租户字段与权限校验策略（TenantId、UserId）。

## 输出物

- 项目结构与规范清单确认
- 依赖服务配置清单
- 模块范围与边界说明
