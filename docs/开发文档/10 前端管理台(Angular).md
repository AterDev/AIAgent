# 10 前端管理台（Angular）

## 目标

提供管理端 UI，覆盖模型、RAG、Agent、MCP、工作流等功能，支持执行监控与审计。

## 步骤

1. **基础结构**
   - 按模块规划路由：模型、文档、工具、Agent、工作流、日志。
   - 公共组件放置于 shared/components。

2. **模型管理**
   - 列表、详情、启用/禁用、能力标签。
   - 配置提供商与路由策略。

3. **应用管理**
   - 应用列表、详情、密钥管理。
   - 应用配额与限流配置。
   - 应用可用模型与工具配置。

4. **系统配置与提示词**
   - 提示词分组管理与模板编辑。

5. **知识库与 RAG 文档管理**
   - 上传、分类、解析状态展示。
   - 检索页面（查询 + 结果 + 相关度）。

6. **MCP 工具管理**
   - 工具列表与详情。
   - 工具执行测试面板。

7. **Agent 管理**
   - Agent 配置编辑器（系统提示词、工具选择、模型）。
   - 执行面板（流式输出）。

8. **工作流管理**
   - 工作流列表与发布状态。
   - 运行与进度监控页面。

9. **日志与监控**
   - 模型调用统计。
   - Agent/工作流执行记录列表。

## 验收要点

- 核心功能入口完整可用。
- 与后端 API 对齐。
