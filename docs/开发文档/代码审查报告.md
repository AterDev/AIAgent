## 🔴 阻断性问题（必须修复）

### BE-001: OpenAI SDK未集成，模型调用不可用
**严重程度**: 🔴 Critical  
**位置**: [OpenAiCompatibleClient.cs](src/Modules/CoreMod/Services/OpenAiCompatibleClient.cs), [Directory.Packages.props](Directory.Packages.props)

**问题描述**:  
CoreMod中的OpenAiCompatibleClient是占位实现，Directory.Packages.props中未引用Azure.AI.OpenAI或OpenAI包，导致无法调用任何LLM模型。

**影响**:  
整个系统核心功能（Agent、工作流、RAG）完全不可用。

**修复建议**:
```xml
<!-- Directory.Packages.props -->
<PackageVersion Include="Azure.AI.OpenAI" Version="2.1.0" />
```

```csharp
// OpenAiCompatibleClient.cs
public class OpenAiCompatibleClient(AzureOpenAIClient client, IConfiguration config)
{
    public async Task<ModelResponse> ChatAsync(ModelRequest request, CancellationToken ct)
    {
        var options = new ChatCompletionsOptions
        {
            Messages = { new ChatRequestUserMessage(request.Prompt) },
            MaxTokens = request.MaxTokens,
            Temperature = request.Temperature
        };
        
        var response = await client.GetChatCompletionsClient(request.ModelName)
            .CompleteAsync(options, ct);
        
        return new ModelResponse { Content = response.Value.Content[0].Text };
    }
}
```

### BE-002: Embedding生成使用MD5哈希而非真实向量
**严重程度**: 🔴 Critical  
**位置**: [HashEmbeddingGenerator.cs](src/Modules/KnowledgeBaseMod/Services/HashEmbeddingGenerator.cs#L14-L24)

**问题描述**:  
HashEmbeddingGenerator使用MD5哈希生成向量，无法用于语义相似度搜索，导致RAG检索完全失效。

**影响**:

**修复建议**:
```csharp
public class CoreModelEmbeddingGenerator(IModelInvokeFacade modelRouter) : IEmbeddingGenerator
{
    public async Task<float[]> GenerateAsync(string text, CancellationToken ct)
    {
        var request = new ModelRequest 
        { 
            ModelName = "text-embedding-3-small",
            Prompt = text 
        };
        var response = await modelRouter.EmbedAsync(request, ct);
        return response.Embedding;
    }
}
```

### BE-003: 文档解析器为占位实现
**严重程度**: 🔴 Critical  
**位置**: [SimpleDocumentParser.cs](src/Modules/KnowledgeBaseMod/Services/SimpleDocumentParser.cs)

**问题描述**:  
SimpleDocumentParser只能处理纯文本，无法解析PDF、Word、Excel、图片等格式。

**影响**:  
用户上传的常见文档格式无法处理，严重影响可用性。

**修复建议**:
```csharp
// 使用开源库
// PDF: iText7 或 PdfPig
// Word: DocumentFormat.OpenXml
// Excel: ClosedXML 或 EPPlus
// OCR: 调用Vision模型处理扫描件和图片

public class PdfDocumentParser : IDocumentParser
{
    public async Task<string> ParseAsync(Stream stream, CancellationToken ct)
    {
        using var reader = new PdfReader(stream);
        using var document = new PdfDocument(reader);
        var text = new StringBuilder();
        for (int i = 1; i <= document.GetNumberOfPages(); i++)
        {
            text.AppendLine(PdfTextExtractor.GetTextFromPage(document.GetPage(i)));
        }
        return text.ToString();
    }
}
```

**参考**: [功能说明 - 支持的文档格式](docs/0%20总体功能说明.md#支持的文档格式)

### BE-004: Agent执行链路不完整
**严重程度**: 🔴 Critical  
**位置**: [AgentExecutionService.cs](src/Modules/AIAgentMod/Services/AgentExecutionService.cs#L68-L80)

**问题描述**:  
AgentExecutionService只支持单次工具调用，无法处理多轮对话和复杂工具链路。

**影响**:  
Agent智能能力严重受限，无法完成复杂任务。

**修复建议**:
```csharp
public async Task<AgentResponse> ExecuteAsync(Guid agentId, string input, CancellationToken ct)
{
    var agent = await GetAgentAsync(agentId, ct);
    var messages = new List<ChatMessage> { new UserMessage(input) };
    var maxIterations = 10;
    
    for (int i = 0; i < maxIterations; i++)
    {
        // 1. 调用模型
        var response = await _modelRouter.ChatAsync(new ModelRequest 
        { 
            Messages = messages,
            Tools = agent.Tools 
        }, ct);
        
        // 2. 如果是工具调用，执行工具并继续
        if (response.ToolCalls?.Any() == true)
        {
            foreach (var toolCall in response.ToolCalls)
            {
                var result = await _toolExecutor.ExecuteAsync(toolCall, ct);
                messages.Add(new ToolMessage(toolCall.Id, result));
            }
            continue;
        }
        
        // 3. 返回最终响应
        return new AgentResponse { Content = response.Content };
    }
    
    throw new BusinessException("Agent执行超过最大迭代次数");
}
```

**参考**: [技术设计文档 - Agent模块](docs/1%20技术详细设计文档.md#agent-模块)
