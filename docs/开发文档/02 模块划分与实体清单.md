# 02 模块划分与实体清单

## 目标

按模块划分实体与职责，保证边界清晰且可复用。

## 模块划分

- **CoreMod**：大语言模型调用封装（统一调用、计量、日志）
- **ModelMod**：模型管理（模型与提供商配置）
- **KnowledgeBaseMod**：知识库、文件解析训练与 RAG
- **McpMod**：MCP 工具注册与执行
- **WorkflowMod**：工作流定义与执行
- **AIAgentMod**：Agent 配置、执行、运行记录
- **SystemMod**：系统配置（含提示词管理复用 SystemConfig）
- **Services**：对外 API（ApiService）与管理后台 API（AdminService）

## 实体清单（按模块）

### CoreMod

- （无业务实体，提供跨模块调用封装）

### ModelMod

- 应用管理
  - Application（应用定义与权限）
  - ApplicationQuota（应用配额与限流）
  - ApplicationModelPermission（应用-模型可用关系）
- 模型管理
  - ModelProfile（模型元数据与能力）
  - ModelProvider（提供商/渠道配置）
  - ModelInvocation（统一调用记录，含 token 统计、耗时、状态）

### KnowledgeBaseMod

- 知识库与 RAG
  - RagCollection（知识库/文档集）
  - RagDocument
  - RagChunk

### McpMod

- MCP 工具
  - McpTool
  - ToolCallRecord

### AIAgentMod

- Agent
  - Agent
  - AgentExecution

### WorkflowMod

- Workflow
  - Workflow
  - WorkflowExecution

### SystemMod

- SystemConfig（系统配置与提示词管理复用）

## 实体落位

- Definition/Entity/CommonMod
- Definition/Entity/ModelMod
- Definition/Entity/KnowledgeBaseMod
- Definition/Entity/McpMod
- Definition/Entity/WorkflowMod
- Definition/Entity/AIAgentMod
- Definition/Entity/SystemMod
- 对应 EF 配置与迁移放在 Definition/EntityFramework

## 约束与规范

- 实体继承 EntityBase（Id/CreatedAt/UpdatedAt/IsDeleted）
- Id 使用 Guid v7（客户端生成）
- 字符串长度、枚举 Description、精度字段严格标注
- 所有实体包含 TenantId/CreatedByUserId 等多租户/审计字段

## 输出物

- 实体类草案与字段清单
- 模块依赖与引用方向说明
