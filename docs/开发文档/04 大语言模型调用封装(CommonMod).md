# 04 大语言模型调用封装（CoreMod）

## 目标

提供跨模块复用的模型调用封装，仅包含技术性调用逻辑，不包含业务规则与用量记录。

## 步骤

1. **统一调用接口**
   - IModelClient：统一的调用入口（Chat/Embedding/Moderation/Vision）。
   - IModelRouter：默认以兼容 OpenAI 接口为路由准则。
   - IModelCapabilityResolver：能力查询与兼容性判断。
   - IUsageMeter：从响应中解析 token 使用情况。

2. **适配器实现**
   - OpenAI Responses API 适配器（优先）。
   - 兼容旧 ChatCompletions 适配器（仅兜底）。
   - 国产模型适配器（与 OpenAI 标准对齐）。

3. **请求/响应规范化**
   - 统一消息格式与工具调用结构。
   - 支持流式响应。

4. **可靠性处理**
   - 超时、重试与降级策略。
   - 统一错误码与异常映射。

5. **扩展与观测**
   - 提供调用钩子供业务模块写入记录与统计。
   - 记录基础日志与追踪信息（不落业务数据）。

## 验收要点

- 不同模型提供商可通过同一接口调用。
- 工具调用与流式响应正常工作。
