# 存储服务商功能补充

要实现知识库，必须先要能够管理文件。而要想管理文件,需要配置和提供存储服务商。

现在提供两种模式:
1. 本地存储（默认）
2. AWSS3存储

该实体属于系统模块

## 实现

### 后端实现

创建新的实体`StorageProvider`，用于存储服务商的信息，包含：

- Name: 存储服务商名称, 长度60
- IsCloud: 是否为云存储, 布尔值
- Path: 本地存储路径, 长度200
- Endpoint: 访问端点, 长度200
- AccessKeyId: 访问密钥, 长度100
- AccessKeySecret: 访问密钥密码, 长度100
- BucketName: 存储桶名称 ,长度100
- Region: 存储区域，可选, 长度100
- IsActive: 是否启用

然后通过Perigon MCP生成基本的DTO/Manager/Controller代码。

> 注意，当有多个存储服务商时，只能有一个启用状态，也就是更新时，需要将其他的服务商设置为未启用。

修改现有的上传文件逻辑，不再从配置中读取，而是从启用的存储服务商中读取配置信息，然后进行文件上传。

### 前端页面

先使用Perigon 生成前端请求服务。

- 编写新的组件，来实现存储服务商的管理功能。
- 添加对应的路由配置和菜单(存储配置)，以及页面的多语言支持。
