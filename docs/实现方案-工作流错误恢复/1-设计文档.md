# 实现方案：工作流错误恢复与状态持久化

## 1. 概述

### 问题分析
- **现状**: 工作流执行失败后无法恢复，中间步骤未保存，长时间运行不稳定
- **风险**: 用户无法追踪执行进度，一旦失败需要重新运行，浪费计算成本
- **目标**: 实现工作流状态完整持久化、断点续传、自动重试等生产级能力

### 核心目标
- ✅ 每步执行状态实时保存
- ✅ 断点续传（失败后可从失败步骤重新执行）
- ✅ 自动重试机制（指数退避）
- ✅ 完整的执行日志和审计追踪
- ✅ 实时进度通知（WebSocket）

## 2. 架构设计

### 2.1 状态转换图

```
        ┌─────────────┐
        │   Pending   │  (初始化完成，等待执行)
        └──────┬──────┘
               │
               ▼
        ┌─────────────┐
        │   Running   │  (执行中)
        └──────┬──────┘
               │
        ┌──────┴──────┐
        │             │
        ▼             ▼
    ┌────────┐  ┌──────────────┐
    │Completed│  │ Failed       │  (失败，可重试)
    └────────┘  └──────┬───────┘
                       │
                  ┌────┴────┐
                  │          │
                  ▼          ▼
            ┌────────┐  ┌──────────┐
            │Retrying│  │Abandoned │  (放弃)
            └──────┬─┘  └──────────┘
                   │
        ┌──────────┴──────────┐
        │                     │
        ▼                     ▼
    ┌──────────┐      ┌──────────────┐
    │Completed │      │ Failed Again │
    └──────────┘      └──────┬───────┘
                             │
                          (retry)
```

### 2.2 数据持久化层次

```
WorkflowExecution (主记录)
  ├─ Status (总体状态)
  ├─ ExecutedStepCount (已执行步数)
  ├─ StepExecutions[] (每步执行记录)
  │   ├─ Step Name
  │   ├─ Status
  │   ├─ Input
  │   ├─ Output
  │   ├─ Error
  │   ├─ Retry Count
  │   ├─ DurationMs
  │   └─ Timestamp
  ├─ Context (全局上下文)
  ├─ ErrorMessage (最后一个错误)
  └─ LastCheckpoint (最后有效检查点)
```

```csharp
/// <summary>
/// 增强的工作流执行器（带状态恢复）
/// </summary>
public interface IWorkflowExecutionManager

    /// 执行工作流
    /// </summary>
    Task<bool> ExecuteAsync(Guid executionId, CancellationToken cancellationToken = default);

    /// </summary>
```

### 4.2 实现类

```csharp
namespace WorkflowMod.Services;

public class DefaultWorkflowExecutionManager(
    TenantDbFactory dbContextFactory,
    IUserContext userContext,
    IModelInvokeFacade modelInvokeFacade,
    IRagQueryFacade ragQueryFacade,
    IMcpToolExecutorFacade mcpToolExecutorFacade,
    ISystemConfigFacade systemConfigFacade,
    IAgentExecutionService agentExecutionService,
    ILogger<DefaultWorkflowExecutionManager> logger
) : IWorkflowExecutionManager
{
    private const int StepTimeoutSeconds = 300;  // 5 分钟超时
    private const int DefaultMaxRetries = 3;

    public async Task<bool> ExecuteAsync(Guid executionId, CancellationToken cancellationToken = default)
    {
        await using var dbContext = await dbContextFactory.CreateDbContextAsync();
        var execution = await dbContext.WorkflowExecutions.FindAsync(new object[] { executionId }, cancellationToken: cancellationToken);

        if (execution == null)
            throw new BusinessException("Execution not found");

        return await ExecuteInternalAsync(execution, 0, dbContext, cancellationToken);
    }

    public async Task<bool> ResumeAsync(Guid executionId, int fromStepIndex, CancellationToken cancellationToken = default)
    {
        await using var dbContext = await dbContextFactory.CreateDbContextAsync();
        var execution = await dbContext.WorkflowExecutions.FindAsync(new object[] { executionId }, cancellationToken: cancellationToken);

        if (execution == null)
            throw new BusinessException("Execution not found");

        if (execution.Status == WorkflowExecutionStatus.Completed)
            throw new BusinessException("Execution already completed");

        execution.Status = WorkflowExecutionStatus.Running;
        execution.ExecutionMode = WorkflowExecutionMode.Resumed;
        execution.ResumedAt = DateTime.UtcNow;
        execution.UpdatedAt = DateTime.UtcNow;
        await dbContext.SaveChangesAsync(cancellationToken);

        logger.LogInformation("Resuming execution {ExecutionId} from step {StepIndex}", executionId, fromStepIndex);

        return await ExecuteInternalAsync(execution, fromStepIndex, dbContext, cancellationToken);
    }

    public async Task<bool> CancelAsync(Guid executionId, CancellationToken cancellationToken = default)
    {
        await using var dbContext = await dbContextFactory.CreateDbContextAsync();
        var execution = await dbContext.WorkflowExecutions.FindAsync(new object[] { executionId }, cancellationToken: cancellationToken);

        if (execution == null)
            return false;

        execution.Status = WorkflowExecutionStatus.Abandoned;
        execution.IsAbandoned = true;
        execution.UpdatedAt = DateTime.UtcNow;
        await dbContext.SaveChangesAsync(cancellationToken);

        return true;
    }

    public async Task<WorkflowExecutionProgress> GetProgressAsync(Guid executionId, CancellationToken cancellationToken = default)
    {
        await using var dbContext = await dbContextFactory.CreateDbContextAsync();
        var execution = await dbContext.WorkflowExecutions.FindAsync(new object[] { executionId }, cancellationToken: cancellationToken);

        if (execution == null)
            throw new BusinessException("Execution not found");

        var stepExecutions = JsonSerializer.Deserialize<List<StepExecution>>(execution.StepExecutionsJson) ?? [];

        return new WorkflowExecutionProgress
        {
            ExecutionId = executionId,
            Status = execution.Status,
            TotalSteps = execution.Workflow?.DefinitionJson?.Length ?? 0,  // 需要计算步骤数
            CompletedSteps = stepExecutions.Count(s => s.Status == StepExecutionStatus.Completed),
            FailedSteps = stepExecutions.Count(s => s.Status == StepExecutionStatus.Failed),
            ProgressPercentage = stepExecutions.Count > 0 
                ? (stepExecutions.Count(s => s.Status == StepExecutionStatus.Completed) * 100.0) / stepExecutions.Count 
                : 0,
            Steps = stepExecutions.Select(s => new StepExecutionInfo
            {
                Index = s.Index,
                Name = s.Name,
                Status = s.Status,
                DurationMs = s.DurationMs,
                ErrorMessage = s.ErrorMessage
            }).ToList(),
            ErrorMessage = execution.ErrorMessage
        };
    }

    public async Task<bool> RetryAsync(Guid executionId, CancellationToken cancellationToken = default)
    {
        await using var dbContext = await dbContextFactory.CreateDbContextAsync();
        var execution = await dbContext.WorkflowExecutions.FindAsync(new object[] { executionId }, cancellationToken: cancellationToken);

        if (execution == null)
            return false;

        if (execution.RetryCount >= execution.MaxRetries)
        {
            execution.IsAbandoned = true;
            execution.Status = WorkflowExecutionStatus.Abandoned;
            logger.LogWarning("Execution {ExecutionId} has exceeded max retries", executionId);
            await dbContext.SaveChangesAsync(cancellationToken);
            return false;
        }

        execution.RetryCount++;
        execution.Status = WorkflowExecutionStatus.Retrying;
        execution.UpdatedAt = DateTime.UtcNow;
        await dbContext.SaveChangesAsync(cancellationToken);

        // 计算延迟（指数退避）
        var delayMs = (int)Math.Pow(2, execution.RetryCount) * 1000;
        await Task.Delay(delayMs, cancellationToken);

        // 从上一个检查点重新执行
        var fromStepIndex = execution.LastCheckpointStepIndex ?? 0;
        return await ResumeAsync(executionId, fromStepIndex, cancellationToken);
    }

    private async Task<bool> ExecuteInternalAsync(
        WorkflowExecution execution,
        int startStepIndex,
        DefaultDbContext dbContext,
        CancellationToken cancellationToken
    )
    {
        var workflow = await dbContext.Workflows.FindAsync(new object[] { execution.WorkflowId }, cancellationToken: cancellationToken);
        if (workflow == null)
            return false;

        var steps = ParseWorkflowSteps(workflow.DefinitionJson);
        var context = JsonSerializer.Deserialize<Dictionary<string, object?>>(execution.ContextJson) 
            ?? new Dictionary<string, object?>();

        var stepExecutions = JsonSerializer.Deserialize<List<StepExecution>>(execution.StepExecutionsJson) 
            ?? new List<StepExecution>();

        execution.Status = WorkflowExecutionStatus.Running;
        await dbContext.SaveChangesAsync(cancellationToken);

        var stopwatch = Stopwatch.StartNew();

        try
        {
            for (int i = startStepIndex; i < steps.Count; i++)
            {
                if (execution.IsAbandoned)
                {
                    execution.Status = WorkflowExecutionStatus.Abandoned;
                    break;
                }

                var step = steps[i];
                var stepExecution = new StepExecution
                {
                    Index = i,
                    Name = step.Name,
                    Status = StepExecutionStatus.Running,
                    StartTime = DateTime.UtcNow
                };

                var stepStopwatch = Stopwatch.StartNew();

                try
                {
                    // 执行步骤
                    var stepContext = new Dictionary<string, object?>(context);
                    var result = await ExecuteStepWithRetryAsync(step, stepContext, i, cancellationToken);

                    stepStopwatch.Stop();
                    stepExecution.Output = result;
                    stepExecution.Status = StepExecutionStatus.Completed;
                    stepExecution.DurationMs = (int)stepStopwatch.ElapsedMilliseconds;
                    stepExecution.EndTime = DateTime.UtcNow;

                    // 更新全局上下文
                    context[step.Name] = result;

                    // 保存检查点
                    execution.LastCheckpointStepIndex = i;
                    execution.ContextJson = JsonSerializer.Serialize(context);

                    stepExecutions.Add(stepExecution);
                    execution.StepExecutionsJson = JsonSerializer.Serialize(stepExecutions);
                    execution.ExecutedStepCount = i + 1;
                    execution.UpdatedAt = DateTime.UtcNow;
                    await dbContext.SaveChangesAsync(cancellationToken);

                    logger.LogInformation("Step {StepName} completed in {Ms}ms", step.Name, stepExecution.DurationMs);
                }
                catch (Exception ex)
                {
                    stepStopwatch.Stop();
                    stepExecution.Status = StepExecutionStatus.Failed;
                    stepExecution.ErrorMessage = ex.Message;
                    stepExecution.DurationMs = (int)stepStopwatch.ElapsedMilliseconds;
                    stepExecution.EndTime = DateTime.UtcNow;

                    stepExecutions.Add(stepExecution);
                    execution.StepExecutionsJson = JsonSerializer.Serialize(stepExecutions);
                    execution.Status = WorkflowExecutionStatus.Failed;
                    execution.ErrorMessage = $"Step '{step.Name}' failed: {ex.Message}";
                    execution.UpdatedAt = DateTime.UtcNow;
                    await dbContext.SaveChangesAsync(cancellationToken);

                    logger.LogError(ex, "Step {StepName} failed", step.Name);

                    // 自动重试
                    if (execution.RetryCount < execution.MaxRetries)
                    {
                        var delayMs = (int)Math.Pow(2, execution.RetryCount + 1) * 1000;
                        logger.LogInformation("Retrying execution in {Ms}ms (attempt {Attempt}/{Max})", delayMs, execution.RetryCount + 1, execution.MaxRetries);
                        
                        await Task.Delay(delayMs, cancellationToken);
                        execution.RetryCount++;
                        execution.Status = WorkflowExecutionStatus.Retrying;
                        await dbContext.SaveChangesAsync(cancellationToken);

                        // 重新执行当前步骤
                        i--; // 回退到当前步骤
                        continue;
                    }

                    return false;
                }
            }

            stopwatch.Stop();
            execution.Status = WorkflowExecutionStatus.Completed;
            execution.OutputJson = JsonSerializer.Serialize(context);
            execution.CompletedTime = DateTimeOffset.UtcNow;
            execution.DurationMs = (int)stopwatch.ElapsedMilliseconds;
            await dbContext.SaveChangesAsync(cancellationToken);

            logger.LogInformation("Workflow {WorkflowId} completed successfully in {Ms}ms", execution.WorkflowId, execution.DurationMs);
            return true;
        }
        catch (Exception ex)
        {
            stopwatch.Stop();
            execution.Status = WorkflowExecutionStatus.Failed;
            execution.ErrorMessage = ex.Message;
            execution.CompletedTime = DateTimeOffset.UtcNow;
            execution.DurationMs = (int)stopwatch.ElapsedMilliseconds;
            execution.UpdatedAt = DateTime.UtcNow;
            await dbContext.SaveChangesAsync(cancellationToken);

            logger.LogError(ex, "Workflow {WorkflowId} execution failed", execution.WorkflowId);
            return false;
        }
    }

    private async Task<Dictionary<string, object?>> ExecuteStepWithRetryAsync(
        WorkflowStep step,
        Dictionary<string, object?> context,
        int stepIndex,
        CancellationToken cancellationToken,
        int retryCount = 0
    )
    {
        try
        {
            // 使用 timeout token
            using var cts = CancellationTokenSource.CreateLinkedTokenSource(cancellationToken);
            cts.CancelAfter(TimeSpan.FromSeconds(StepTimeoutSeconds));

            return await ExecuteStepAsync(step, context, cts.Token);
        }
        catch (OperationCanceledException) when (retryCount < 2)
        {
            logger.LogWarning("Step {StepName} timed out, retrying (attempt {Attempt})", step.Name, retryCount + 1);
            await Task.Delay(1000 * (retryCount + 1), cancellationToken);
            return await ExecuteStepWithRetryAsync(step, context, stepIndex, cancellationToken, retryCount + 1);
        }
    }

    private async Task<Dictionary<string, object?>> ExecuteStepAsync(
        WorkflowStep step,
        Dictionary<string, object?> context,
        CancellationToken cancellationToken
    )
    {
        var result = new Dictionary<string, object?>();

        switch (step.Kind)
        {
            case WorkflowStepKind.ModelCall:
                result[step.Name] = await ExecuteModelStepAsync(step, context, cancellationToken);
                break;
            case WorkflowStepKind.ToolCall:
                result[step.Name] = await ExecuteToolStepAsync(step, context, cancellationToken);
                break;
            case WorkflowStepKind.RagQuery:
                result[step.Name] = await ExecuteRagStepAsync(step, context, cancellationToken);
                break;
            case WorkflowStepKind.AgentCall:
                result[step.Name] = await ExecuteAgentStepAsync(step, context, cancellationToken);
                break;
            default:
                throw new BusinessException($"Unsupported step type: {step.Type}");
        }

        return result;
    }

    // ... 其他执行方法（保持原有逻辑）
}
```

## 5. 恢复和重试策略

### 5.1 重试策略

```csharp
public class RetryPolicy
{
    /// <summary>
    /// 最大重试次数
    /// </summary>
    public int MaxAttempts { get; set; } = 3;

    /// <summary>
    /// 初始延迟（毫秒）
    /// </summary>
    public int InitialDelayMs { get; set; } = 1000;

    /// <summary>
    /// 延迟倍数（指数退避）
    /// </summary>
    public double BackoffMultiplier { get; set; } = 2.0;

    /// <summary>
    /// 最大延迟（毫秒）
    /// </summary>
    public int MaxDelayMs { get; set; } = 30000;

    /// <summary>
    /// 可重试的异常类型
    /// </summary>
    public List<Type> RetryableExceptions { get; set; } = new()
    {
        typeof(TimeoutException),
        typeof(HttpRequestException),
        typeof(InvalidOperationException)
    };

    public int GetDelayMs(int attemptNumber)
    {
        var delay = (int)(InitialDelayMs * Math.Pow(BackoffMultiplier, attemptNumber - 1));
        return Math.Min(delay, MaxDelayMs);
    }
}
```
